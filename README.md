#Title: Unit and Integration Testing for Age Verification Component

#Description:
Developed and implemented unit and integration tests for the AgeChecker component, ensuring robust functionality and proper validation of user inputs. Utilized React Testing Library to simulate user interactions, such as input changes and button clicks, and verified application behavior under various conditions.

#Key achievements:

Tested multiple edge cases, including scenarios for users under and above 18 years of age.
Used asynchronous assertions (e.g., screen.findByText) to handle loading states and dynamic updates.
Validated the absence of incorrect or unnecessary elements during component rendering (e.g., "Loading..." or incorrect messages).
Ensured comprehensive test coverage for core component logic, including proper handling of user inputs, focus events, and conditional rendering.
Applied testing best practices to improve code reliability and maintainability.
Tools and technologies used:

React Testing Library: For simulating DOM events and validating component output.
Jest: As the testing framework.
Mocked data and constants: Ensured dynamic behavior of UI based on input values.
Playwright for e2e test
